# AdlibTracker2Replay
A WatcomC/OpenWatcom/DJGPP music replayer for the !Surprise Productions Adlib Tracker 2

You can find a interrupt based version here:  
https://github.com/kosmonautdnb/WatcomLibs  
look for app_sa2.cpp

# Remarks
Just a quick conversion, the program was converted from 286er segmented assembly to 386 FlatMode C++ in a hurry. If there are bugs left maybe I fix them soonish.. This was just meant for internal use and is not ready for a big release. However our demosongs play well already with it. You can create the needed .sa2 file with the S!P Adlib Tracker 2 to be found here: https://www.pouet.net/prod.php?which=70029
